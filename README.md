# Тетерина Юлия ИТ-16

## Реализация паттернов
1. **Singleton (DatabaseConnection)**  
Где применяется: Сервис каталога и рецептов.  
Задача: Единое подключение к базе данных, чтобы не создавать лишние соединения при каждом запросе.

3. **Factory Method (PaymentProcessor)**  
Где применяется: Сервис оплаты.  
Задача: Создание обработчика платежа (Карта, Наличные, Перевод) в зависимости от выбора клиента.

4. **Adapter (Notifier)**  
Где применяется: Сервис заказов и клиентов.  
Задача: Отправка уведомлений в Telegram и WhatsApp через единый интерфейс.

5. **Facade (OrderFacade)**  
Где применяется: API Gateway (связующее звено).  
Задача: Упростить оформление заказа (проверка ингредиентов + расчет цены + создание заказа) в один вызов.

6. **Proxy (Recipe)**  
Где применяется: Сервис каталога и рецептов.  
Задача: Кэширование рецептов, чтобы не нагружать базу данных повторными запросами.
